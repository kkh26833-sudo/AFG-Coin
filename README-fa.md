# پروژه AFG Coin — بسته شروع توسعه

**نام پیشنهادی:** Afghanistan Coin  
**نماد پیشنهادی:** AFG  
**شبکه هدف:** Solana  
**استاندارد نسخه اول:** SPL Token (برنامه اصلی توکن)  
**عرضه هدف:** 1,000,000,000 AFG  
**اعشار:** 6  
**وضعیت:** پروژه آماده آزمایش؛ هنوز هیچ توکن Mainnet ساخته یا منتشر نشده است.

## مهم: واقعیت هزینه‌ها
- طراحی، کدنویسی، وب‌سایت ایستا و آزمایش محلی/Devnet را می‌توان بدون پرداخت پول واقعی انجام داد.
- تراکنش‌های Devnet با SOL آزمایشی انجام می‌شوند که ارزش مالی ندارد.
- ساخت توکن روی Mainnet، ایجاد حساب‌ها و عرضه/بازار واقعی به SOL و هزینه‌های شبکه/سرویس نیاز دارد؛ بنابراین «ساخت واقعی با صفر یورو» تضمین‌پذیر نیست.
- این بسته هیچ تراکنش واقعی را خودکار اجرا نمی‌کند. اسکریپت Mainnet عمداً قفل تأیید دارد.

## ساختار پروژه
- `website/` وب‌سایت معرفی ایستا و واکنش‌گرا
- `scripts/devnet-create.sh` ساخت توکن آزمایشی و عرضه یک میلیارد توکن در Devnet
- `scripts/mainnet-create.sh` نمونه اسکریپت Mainnet با قفل تأیید دستی
- `docs/TOKENOMICS-fa.md` سیاست عرضه و ریسک‌ها
- `docs/SECURITY-fa.md` چک‌لیست امنیت
- `token-metadata.json` داده اولیه متادیتا (برای انتشار URI عمومی باید میزبانی شود)

## پیش‌نیازها
1. کامپیوتر شخصی؛ برای Windows از WSL استفاده کنید.
2. Solana CLI و SPL Token CLI مطابق مستندات رسمی نصب شوند.
3. یک کیف پول/کلید آزمایشی جدا از کیف پول شخصی اصلی بسازید.
4. هرگز عبارت بازیابی یا فایل کلید خصوصی را برای کسی ارسال نکنید و داخل وب‌سایت قرار ندهید.

مستندات رسمی نصب: https://solana.com/docs/intro/installation  
راهنمای رسمی ساخت توکن: https://solana.com/docs/tokens/quickstart

## آزمایش Devnet (رایگان)
در ترمینال وارد پوشه پروژه شوید:
```bash
chmod +x scripts/*.sh
./scripts/devnet-create.sh
```
اسکریپت:
- شبکه را روی Devnet تنظیم می‌کند.
- برای کیف پول فعال درخواست SOL آزمایشی می‌دهد (اگر شکست خورد راهنمایی به Faucet می‌کند).
- Mint ایجاد می‌کند و آدرس را تا حد امکان خودکار تشخیص می‌دهد.
- حساب توکن کیف پول را می‌سازد.
- دقیقاً یک میلیارد توکن با ۶ رقم اعشار Mint می‌کند.
- اختیار Mint و Freeze را پس از تأیید شما غیرفعال می‌کند.
- آدرس Mint و لینک Explorer را نمایش می‌دهد.

### دریافت SOL آزمایشی از Faucet رسمی
اگر airdrop خودکار کار نکرد:
1. به آدرس زیر بروید: **https://faucet.solana.com/**
2. شبکه را روی **Devnet** بگذارید
3. آدرس کیف پول خود را وارد کنید (با دستور `solana address`)
4. درخواست SOL بدهید
5. چند ثانیه صبر کنید و با `solana balance` موجودی را چک کنید

**توجه:** اسکریپت تنظیمات پیش‌فرض Solana CLI را به Devnet تغییر می‌دهد. پیش از اجرا `solana config get` را ببینید. این کار کیف پول Mainnet را خرج نمی‌کند، اما حتماً از کلید آزمایشی جدا استفاده کنید.

## Mainnet
`mainnet-create.sh` فقط یک الگوی کنترل‌شده است. پیش از اجرای آن:
- کیف پول اختصاصی پروژه را بسازید و فقط به اندازه لازم شارژ کنید.
- هزینه rent، کارمزد، میزبانی metadata و نقدینگی را برآورد کنید.
- نام و نماد AFG و حقوق استفاده از آن را بررسی کنید.
- متادیتا و تصویر را در میزبان پایدار منتشر کنید.
- کد را با توسعه‌دهنده مستقل بازبینی کنید.
- متغیر `CONFIRM_MAINNET=I_UNDERSTAND_REAL_FUNDS` را فقط پس از بررسی آگاهانه تنظیم کنید.

هیچ seed phrase، private key یا فایل wallet را در این مخزن commit نکنید.

## متادیتا و فهرست‌شدن
این بسته یک فایل JSON اولیه دارد؛ صرف وجود آن باعث نمایش خودکار نام/لوگو در همه کیف پول‌ها و صرافی‌ها نمی‌شود. باید URI عمومی و پایدار برای JSON و تصویر ایجاد و روش متادیتای سازگار با استاندارد نهایی انتخاب شود. این پروژه در نسخه اول از SPL Token کلاسیک استفاده می‌کند؛ اتصال متادیتای Metaplex و سازگاری بازارها باید پیش از Mainnet جداگانه پیاده‌سازی و آزمایش شود.
