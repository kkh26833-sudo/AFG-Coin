# چک‌لیست امنیت AFG

## کیف پول و کلیدها
- برای توسعه و خزانه از کیف پول‌های جدا استفاده شود.
- عبارت بازیابی در چت، ایمیل، فرم وب‌سایت یا مخزن کد وارد نشود.
- کلید اصلی روی دستگاه آنلاین/سرور وب‌سایت قرار نگیرد.
- برای خزانه اصلی، سخت‌افزار امن یا چندامضایی پس از بررسی فنی در نظر گرفته شود.
- فایل‌های `id.json`, `.env`, `*.key`, `*.pem` هرگز commit نشوند.

## قبل از Mainnet
- اجرای کامل روی Devnet
- بررسی decimals و supply
- بررسی Mint و Freeze Authority
- بررسی آدرس Mint از Explorer
- بازبینی کد و دستورها توسط شخص مستقل
- بررسی متادیتا، URL تصویر و دامنه
- بررسی حقوقی نام/نشان و قوانین محل فعالیت
- اعلام عمومی آدرس‌های رسمی از کانال‌های معتبر

## پس از Mainnet
- ثبت و انتشار آدرس Mint
- تأیید عرضه و اختیارات در Explorer
- انتشار آدرس خزانه و جدول تخصیص
- پشتیبان‌گیری امن از اطلاعات عمومی پروژه
- پایش جعل وب‌سایت، حساب‌های جعلی و لینک‌های فیشینگ

## محدودیت
این چک‌لیست ممیزی امنیتی رسمی نیست و جایگزین audit مستقل نمی‌شود.
